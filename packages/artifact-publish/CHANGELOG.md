# @openge/forge-artifact-publish

## 0.3.0

### Minor Changes

- 664660f: 将制品内容身份改为必需的清单 SHA-256 与可选真实 Git provenance，支持没有 Git 仓库的生产者。新增规范清单 v1 生成入口，绑定路径、摘要、长度、响应策略及控制文件。
  
  这是 0.x 破坏性契约调整：移除 `sourceCommit` 输入，操作记录和对象发布回执升级为 schema 2，旧未知记录拒绝自动迁移或重放。Node 命令关联环境同步更新，并保留受管作用域与确认关闭要求。
  
  迁移 COS 消费契约，增加真实 tarball 的 Node 与严格非 Node workerd/SQLite 重启恢复验收；pending、只读恢复、稳定 reference 与 CAS 仍保持单次操作语义。

## 0.2.0

### Minor Changes

- 0bdc5b3: 新增领域中立的制品操作输入绑定、持久 CAS 占位、独立接受与观察回执及只观察恢复入口。提供显式命令适配器，复用有界命令执行和受管作用域，不把命令退出解释为远端部署就绪。
  
  增加不可变目录激活与静态/OCI/运行多制品两类真实 tarball 消费证明。COS 协议保持现有行为，更新精确 Core 依赖并验证响应丢失后的激活恢复不会重放写入。

## 0.1.0

### Minor Changes

- d2e7ab5: 新增中立不可变对象发布与 COS Provider：受控文件或字节输入、精确完整性与元数据回读、共享传输预算、有界并发和取消、结构化失败收据，以及全部对象验证后的指针切换与已有版本激活。COS 仅支持从未启用版本控制的 bucket；同一指针的所有写入由消费方外部串行协调。
