# 钱包认证

| 包 | 公开入口与职责 |
| --- | --- |
| `@openge/forge-wallet-auth` | 默认入口提供中立的钱包标识、挑战、证明、错误及挑战校验。 |
| `@openge/forge-wallet-auth-evm` | 默认入口提供 SIWE 消息生成、签名校验及显式 ERC-1271 验签适配器。 |
| `@openge/forge-wallet-auth-metamask` | `/browser` 入口发现钱包、请求连接及签名，也可生成 MetaMask 官方深链。 |

产品后端生成并持久化短时挑战，挑战绑定受众、请求地址、登录或绑定用途、钱包账号及独立随机值。浏览器签名后由产品后端按原始挑战验证。成功时在同一产品事务中消费挑战并建立账号关系或会话。跨设备登录使用公开的短时交接标识，发起浏览器保有独立的领取凭据。

普通 EVM 钱包由服务端验证消息签名。产品根据可信账户信息选定验签方式。传入合约验签器时，该请求只通过显式的只读调用适配器在挑战指定的网络上验签。账号、会话、存储、地区策略及业务资产归产品管理。付款凭证核验使用单独的公开边界。

包内消费用例验证出包边界。产品从 npm registry 安装经稳定版验证的精确版本，并在产品锁文件中记录完整性。首次发布按[维护者发布手册](../maintenance/releases.md#首次-bootstrap-新-package)完成 bootstrap 和稳定版发布。
